发表于 2026-03-21
语言与规则处理工具

解析器生成器（Parser Generator）

定义

解析器生成器是一种工具，它根据用户定义的语法规则（通常是上下文无关文法），自动生成能够将字符串转换为抽象语法树（AST） 的代码。它解决的是“如何将文本解析为计算机可理解的结构”这一底层问题。

典型框架

  • ANTLR（支持 Java、Python、JavaScript 等多种语言）
  • JavaCC（Java）
  • Yacc / Bison（C/C++）
  • PEG.js（JavaScript）
  • Lark（Python）

应用领域

  • 开发编程语言（如 Kotlin、Groovy 早期版本使用 ANTLR）
  • 设计领域特定语言（DSL）（如 SQL 解析、配置文件语法）
  • 协议解析（如 JSON、XML、自定义二进制协议）
  • 静态分析工具（如代码格式化器、lint 工具）

表达式解析引擎（Expression Evaluation Engine）

定义

表达式解析引擎专门用于计算单个表达式（如 a + b * c > d）的值。它内部通常也包含解析器（自己实现或用解析器生成器），但对外提供的是简单、直接的求值接口。这类引擎不关心复杂的规则组合和推理。

典型框架

  • Aviator（Java，高性能，语法接近 Java）
  • MVEL（Java，支持表达式和简单脚本）
  • Spring Expression Language (SpEL)（Java，与 Spring 生态集成）
  • ExprTK（C++）
  • eval()（多种语言内置，但安全性较差）

应用领域

  • 动态公式计算（如 Excel 公式、保险费率计算）
  • 配置条件判断（如功能开关：${user.isVip && order.amount > 100}）
  • 报表系统（用户自定义计算字段）
  • 权限表达式（如 subject.hasRole('admin')）

规则引擎（Rule Engine）

定义

规则引擎用于管理、执行一组业务规则，支持基于事实（Fact）的模式匹配、推理链、冲突解决等。它处理的是“如何根据多条规则做出复杂决策”的问题，而非单个表达式计算。

典型框架

  • Drools（Java，功能最全面的开源规则引擎，支持 Rete 算法）
  • EasyRules（Java，轻量级）
  • Jess（Java，基于 CLIPS）
  • ILOG JRules / IBM ODM（商业）
  • NRules（.NET）

应用领域

  • 风控系统（如贷款审批、反欺诈）
  • 业务规则管理（BRMS）（如促销规则、折扣计算）
  • 工作流/审批流（规则驱动的路由）
  • 实时决策（如物联网设备规则引擎）

对比

维度 解析器生成器 表达式解析引擎 规则引擎
核心任务 将字符串转换为语法树 计算单个表达式值 根据一组规则对事实进行推理决策
输入 语法定义文件（如 .g4） 表达式字符串 + 变量上下文 规则集 + 事实对象
输出 词法/语法分析器代码 计算结果（如布尔值、数值） 执行结果（如事实更新、动作触发）
复杂度 高（需要编写语法） 低（开箱即用） 高（需理解规则语言、推理算法）
典型框架 ANTLR, JavaCC, Yacc Aviator, MVEL, SpEL Drools, EasyRules, Jess
应用层次 基础设施层（构建工具） 应用层（轻量计算） 业务层（复杂决策）
是否包含解析器 自身就是生成解析器的工具 内部自带简易解析器 通常自带规则语言解析器（可能基于解析器生成器实现）

三者关系

  • 解析器生成器是构建工具，用于生成解析器，它本身不直接提供表达式求值或规则执行。但表达式引擎和规则引擎都可以基于它来定义自己的语言（例如 Drools 的 DRL 语法早期曾使用 ANTLR 解析）。
  • 表达式解析引擎可以看作是规则引擎的一个子组件——规则的条件部分往往需要表达式求值。因此一些规则引擎内部会集成一个表达式引擎。
  • 规则引擎是最上层的业务决策系统，它可能需要解析器生成器来解析规则语言，也需要表达式引擎来评估条件，但它提供的功能远远超越单纯的解析和求值。

如何选择

  • 如果你需要自定义语法、开发新语言或解析复杂文本格式 → 选择 解析器生成器（如 ANTLR）。
  • 如果你只需要动态计算公式或简单条件 → 选择 表达式解析引擎（如 Aviator）。
  • 如果你需要管理大量业务规则、支持规则的热部署、冲突解决 → 选择 规则引擎（如 Drools）。

三者并不互斥，在大型系统中常常联合使用：用解析器生成器定义规则 DSL，用表达式引擎计算条件，最后用规则引擎执行完整的规则集。
