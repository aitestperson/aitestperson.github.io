openwrt透明代理设置

发表于 2026-11-08

适用场景：OpenWrt 副路由（自建子网）+ Shadowrocket 订阅（含 Trojan 节点），实现”被墙网站走代理、国内网站直连”的透明分流。
硬件参考：小米 Redmi AC2100（mt7621 / mipsel_24kc），其他 OpenWrt 设备思路相同。

openwrt透明代理设置

一、网络拓扑

要点：

  • 副路由自建子网（如 192.168.10.x），连它 WiFi 的设备网关/DNS 都指向它自己，流量 100% 经过它，透明代理必然生效。
  • 主路由设备不受影响：连主路由 WiFi = 直连，连副路由 WiFi = 分流代理。
  • 三个网段（1.x / 31.x / 10.x）互不冲突。

副路由网络配置

WAN 口默认就是 DHCP 客户端，插主路由 LAN 口自动拿 31.x 地址，无需配置。

三、安装 HomeProxy

问题：官方源里没有代理插件

官方 OpenWrt 源里没有 homeproxy / PassWall / OpenClash（只有 shadowsocks-libev，不支持 Trojan）。这些插件在 ImmortalWrt 的源里。

解法：把 ImmortalWrt 的源加为附加源（不用换固件）：

版本号要与固件对应（24.10 系固件用 24.10.0 源），架构看 /etc/openwrt_release 的 DISTRIB_ARCH（如 mipsel_24kc）。
腾讯镜像没有 immortalwrt 目录，404 是正常的，用官方 downloads.immortalwrt.org。

问题：Signature check failed

ImmortalWrt 源带签名，官方固件没有对应公钥，opkg update 会报签名校验失败。关闭全局签名校验（走 https 传输保证安全性）：

问题：老固件源 404

自编译 SNAPSHOT / Lean 固件（R22.x 时代）的 snapshots 源早就删了，无法”换个镜像继续用”。
正确做法：直接 sysupgrade 刷官方 24.10（mt7621 设备官方支持完善）：

刷机注意事项：

  • 刷机过程 3~5 分钟，千万别断电。
  • -n 会清空一切：装的包、配置、SSH 公钥全没了，刷完要重头配。
  • 刷完默认 LAN IP 是 192.168.1.1，网线接 LAN 口连电脑，重新配回 192.168.10.1。
  • WiFi 默认未开/未加密，第一时间在 LuCI 配好。

安装

依赖关系（供排错参考）：

  • luci-app-homeproxy → sing-box、firewall4、kmod-nft-tproxy、ucode-mod-digest
  • sing-box → ca-bundle、kmod-inet-diag、kmod-netlink-diag、kmod-tun

官方 24.10 用 firewall4/nftables，与 ImmortalWrt 24.10 一致，依赖基本都能自动解析。

PassWall2 / OpenClash 对比：PassWall2 也吃 base64 Trojan 订阅、界面更简单，但依赖 dnsmasq-full，需先 opkg remove dnsmasq && opkg install dnsmasq-full（配置在 /etc/config/dhcp，不丢）。OpenClash 还要求把订阅转成 Clash YAML 格式（走第三方 subconverter 服务，订阅 token 会暴露给转换服务，需斟酌）。HomeProxy 最省事。

四、配置 HomeProxy（LuCI 界面）

  1. 服务 → Home Proxy → 节点订阅：填订阅 URL → 保存并更新 → 节点列表出现后，选一个 Trojan 节点作为主节点。
  2. 设置 → 路由模式：选 bypass_mainland_china（大陆白名单） —— 国内直连、国外走代理。这是最实用的默认模式。
  3. 开启透明代理主开关，DNS 劫持默认开启即可。

六、常见问题（FAQ）

Q1：怎么知道某个网站走没走代理？

开着 logread -f | grep 域名，然后访问该网站：

  • 出现 outbound/trojan[main-out] → 走代理
  • 只有 dns 处理、无 trojan 出站或显示 direct → 直连

Q2：怎么改单个网站的分流走向？

加自定义路由规则（优先级高于内置规则集）：

或 LuCI → Home Proxy → 访问控制 → 添加自定义规则。

Q3：bypass_mainland_china 的名单数据在哪？

名单不是本地维护的静态文件，而是 sing-box 的 .srs 规则集，启动时从网上下载并缓存（约每天自动更新一次）：

  • geosite-cn（中国域名）：https://github.com/v2fly/domain-list-community/blob/master/data/cn
  • geoip-cn（中国 IP 段）：APNIC/CNNIC 分配的 CN 地址段
  • 打包源：https://github.com/SagerNet/sing-geosite / https://github.com/SagerNet/sing-geoip

查看本机实际用的规则集 URL：

Q4：订阅 403 / 更新失败？

订阅面板按 User-Agent 过滤。测：

能通的 UA 填进 HomeProxy 订阅设置的 User-Agent 项。都不通则检查订阅是否被重置/过期。
注意：订阅 URL 带 token，等于密码，别公开分享，泄露了去面板重置。

Q5：WiFi 老掉线（mt7621 / mt76 驱动）

掉线时抓现场：logread | grep -iE 'deauth|disassoc'，看 reason=（4=不活跃超时，7=AP 踢）。

Q6：mips 架构选什么二进制？

uname -m 显示 mips，选 linux-mipsle-softfloat（MIPS 小端、软浮点）。amd64/arm64 的跑不了。opkg 不用操心，源路径已锁定架构。

Q7：装了 homeproxy 想换 OpenClash / PassWall2？

OpenClash / PassWall2 也都在 ImmortalWrt 源（iw_luci）里，附加源已加好的话直接装。PassWall2 注意先处理 dnsmasq 冲突（见第三节）。

七、架构速查

架构名 说明 典型设备
mips / mipsel_24kc MIPS 32 位小端 MT7621 路由器（AC2100 等）
amd64 / x86_64 x86 64 位 PC、软路由
arm64 / aarch64 ARM 64 位 树莓派 4、高通 IPQ 系列
armv7 ARM 32 位 老树莓派、ARM 路由器

查看本机：uname -m、opkg print-architecture、cat /etc/openwrt_release。
